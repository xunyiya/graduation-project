# 项目概述

## 项目名称
数据差异对比可视化工具

## 项目背景
本项目来源于毕业设计课题，目标是解决纯文本与结构化文件在差异检测、可视化展示和大文件处理方面的问题。系统面向软件开发、科研分析、企业办公和数据审计等场景。

## 核心问题
1. 传统 diff 工具多偏向纯文本逐行比较
2. 对 JSON、CSV、Excel 等结构化文件支持不足
3. 可视化能力有限，难以直观展示深层差异
4. 大文件场景下容易卡顿
5. 缺少导出、历史记录等完整工作流功能

## 系统目标
1. 支持多格式文件差异检测
2. 支持可视化展示与差异定位
3. 支持差异过滤规则
4. 支持结果导出与历史记录管理
5. 支持大文件性能优化
