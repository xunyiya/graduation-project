# 需求说明

## 功能需求

### 输入功能
- 文件上传
- 路径导入
- 文本粘贴

### 文件类型
- 纯文本
- JSON
- CSV
- Excel

### 差异检测
- 文本逐行 diff
- JSON 节点新增/删除/修改
- CSV 行列差异
- Excel 工作表和单元格差异

### 过滤规则
- 忽略空白字符
- 忽略大小写
- 忽略注释内容

### 可视化
- 左右分栏对比
- 红绿黄高亮
- JSON 树形视图
- 差异统计面板
- 差异跳转

### 结果管理
- 导出 HTML
- 导出 PDF
- 保存历史记录
- 查看历史记录
- 重新查看历史结果

## 非功能需求
- 准确性
- 易用性
- 可扩展性
- 稳定性
- 大文件处理能力
