# Codex 开发规则

## 总原则
1. 不要一次性实现整个系统
2. 必须按阶段开发
3. 每轮开发前先分析方案，再改代码
4. 每轮完成后说明：
   - 修改了哪些文件
   - 如何运行
   - 如何测试
   - 已知风险点

## 开发顺序
1. 项目骨架
2. 文本 diff MVP
3. 文本过滤和行内高亮
4. JSON diff
5. CSV diff
6. Excel diff
7. 差异统计和跳转
8. 导出与历史记录
9. 性能优化
10. 测试和文档整理

## 禁止事项
1. 不要无故重构整个项目
2. 不要删除已工作的模块
3. 不要引入过多依赖
4. 不要在没有说明的情况下修改接口格式
